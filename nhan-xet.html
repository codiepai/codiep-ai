Trợ lý viết nhận xét

Tải file Excel đánh giá xuất từ hệ thống. Công cụ viết nhận xét từng em theo mức đạt được, ghi đúng ô Nội dung và giữ nguyên định dạng file.

Tên và điểm của học sinh chỉ xử lý trong máy thầy cô, không gửi đi đâu.

1. Tải file Excel

Chọn file đánh giá định kỳ môn học hoặc file năng lực phẩm chất (.xlsx) đã xuất từ hệ thống, sau khi đã Ghi mức cho học sinh.

Bấm vào đây hoặc kéo file .xlsx thả vào
Mỗi lần một file

2. Nhận xét từng em

Công cụ chọn câu theo mức, theo môn và ghép khác nhau cho từng em. Ghi chú riêng của cô được thêm vào cuối. Em xếp loại C nên có ghi chú riêng. Nhận xét nào cô sửa tay thì giữ nguyên.

Xem và sửa ngân hàng câu của môn này

3. Tải file đã điền

File mới giữ nguyên định dạng, chỉ thêm nhận xét vào cột Nội dung. Mức và điểm không bị đổi. Chị mở file kiểm tra rồi mới nhập lên hệ thống.
